# ONE MIND — العقل الواحد (MVP)

نسخة تأسيسية قابلة للتشغيل محلياً، ومصممة كنقطة بداية لنقلها إلى بيئة استضافة أو تطوير مثل Google AI Studio.

## ما يعمل الآن
- واجهة عربية RTL متجاوبة.
- أقسام غرفة العقول، مصنع التطوير، البحث، مختبر الإصلاح، المشاريع، والتكاملات.
- روابط مباشرة لمنصات التطوير.
- فحص حالة الخادم ووجود إعداد Gemini.
- محرك تحليل فعلي يستخدم Gemini في أربعة أدوار متخصصة ثم ينشئ خلاصة تحكيمية.
- توضيح صريح أن الأدوار الأربعة تستخدم نموذج Gemini نفسه وليست نماذج مستقلة.

## ما لا يعمل بعد
- لا يوجد ربط فعلي بـ ChatGPT أو Claude أو Perplexity أو DeepSeek أو غيرها.
- لا يوجد تحكم برمجي في Replit أو Lovable أو Bolt أو Cursor بمجرد ظهورها في القائمة.
- البحث على الإنترنت، إدارة المشاريع الدائمة، تشغيل كود المستخدم، وفحص المستودعات تحتاج تكاملات إضافية.

## التشغيل
1. ثبّت Node.js 20 أو أحدث.
2. فك ضغط المشروع.
3. نفّذ `npm install`.
4. انسخ `.env.example` إلى `.env`.
5. أضف مفتاح Gemini إلى `GEMINI_API_KEY` في `.env`.
6. نفّذ `npm run dev`.
7. افتح العنوان الذي يعرضه Vite، عادة `http://localhost:5173`.

## البناء والنشر
- `npm run build`
- `npm start`

في بيئة النشر، أضف `GEMINI_API_KEY` كسرّ خادم (Environment Secret)، ولا تضعه في كود الواجهة أو المستودع.

## ملاحظة حول Google AI Studio
هذا مشروع React + Node مستقل. يمكن استخدام ملفاته مرجعاً عند إنشاء مشروع Build جديد في Google AI Studio أو نقل مكوناته إليه. لا يمكنني الدخول إلى حسابك أو تشغيله داخل مساحة AI Studio الخاصة بك من هنا؛ اختبار التشغيل داخل حسابك يتطلب منك فتح المشروع هناك ومشاركة نتيجة المعاينة أو سجل الخطأ.
